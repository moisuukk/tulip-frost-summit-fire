# Схема одной записи (массив JSON)

Каждый препарат — объект:

- id: kebab-case латиницей
- name_en, name_ru, pronunciation (без скобок)
- synonyms_en: string[]
- trade_names: string[] (без ®)
- class_en, class_ru
- species: массив из "dog" и/или "cat" — только если в книге есть применение, доза или прямой запрет для этого вида
- no_dog_cat_dose: true, если отдельных доз DOGS/CATS нет
- highlights, monitoring, client_info, lab_considerations, dosage_forms: string[] на русском
- indications, pharmacology, pharmacokinetics, contraindications, adverse_effects, reproductive_safety, overdose, storage, stewardship_ru: строка на русском (пустая строка, если в монографии нет)
- interactions: {with_en, with_ru, effect_ru}[]
- dosages: объекты доз

Доза:
- species: "dog" | "cat"
- indication_ru
- dose: строка с числами как в книге, единицами «мг/кг», «мг/собаку», «мг/кошку», «мл/кг», «мг/м²» и пометкой «НЕ мг/кг», если она есть
- route_ru: внутрь | в/в | в/м | п/к | местно | ингаляционно | в конъюнктивальный мешок | ректально | трансдермально | другой короткий русский путь
- frequency_ru
- duration_ru
- regulatory: "label" | "extra-label" | "anecdotal" | "unspecified"
- variant: "" или "a"/"b"/"c"/"d"
- notes_ru: комбинации, условия, предупреждения к этой строке
- source_en: дословный английский фрагмент из книги, в котором есть эта доза (1–3 предложения, без перевода)

Правила:
- Только собаки и кошки. Лошади, КРС, свиньи, овцы, козы, птицы, хорьки, кролики, рептилии — не включать.
- Общая фармакология (механизм), которая верна и для собак/кошек, остаётся. Предложения только про другие виды — выкинуть.
- Если препарат противопоказан кошкам или собакам — это обязательно записать, даже без дозы.
- Не выдумывать числа. Не округлять. Не переводить фунты в килограммы в поле dose (кг из книги можно оставить в notes, если они уже даны).
- Каждая схема a/b/c — отдельный объект dosages. Не склеивать разные дозы в одну строку.
- Помеченные label dosage / FDA-approved → regulatory "label". extra-label → "extra-label". anecdotal → "anecdotal".
- source_en копировать из файла, не перефразировать.
- Формы: ветеринарные для собак/кошек и человеческие, если их применяют этим видам. Интрамаммарные и кормовые для скота не включать, если есть другие формы. Если форм для собак и кошек нет — dosage_forms: ["В монографии нет форм, предназначенных для собак и кошек."] и кратко какие есть только если это нужно для запрета.
- Клиентская информация — перевод пунктов, относящихся к собакам и кошкам.
- Валидный JSON-массив, UTF-8, без markdown.
